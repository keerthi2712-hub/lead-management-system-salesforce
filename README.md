# 🚀 Lead Management System (Salesforce)

## 📌 Overview
This project is a Salesforce-based Lead Management System designed to automate lead prioritization and assignment using business logic and workflow automation.

## 🎯 Objective
To improve lead handling efficiency by automatically categorizing and assigning leads based on predefined criteria.

## ⚙️ Features
- Automated lead scoring based on:
  - Number of Employees
  - Lead Source
  - Expected Deal Value
- Dynamic lead prioritization:
  - High Priority (Score ≥ 7)
  - Medium Priority (Score between 5 and 7)
  - Low Priority (Score < 5)
- Automatic assignment to priority-based queues
- Ownership transfer when a user accepts a lead
- Role-based visibility:
  - Users see only assigned leads
  - Managers can view all leads and assignments

## 🛠️ Tech Stack
- Salesforce CRM
- Salesforce Flows (Automation)
- Lead Objects & Queues

## 🧠 How It Works
1. User enters lead details.
2. System assigns scores to each field.
3. Total score determines lead priority.
4. Lead is routed to the respective queue.
5. When accepted, ownership transfers to the user.
